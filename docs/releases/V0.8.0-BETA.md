# Codex Wallpaper Skin v0.8.0 Beta

[English](#english) | [简体中文](#简体中文)

## 简体中文

`v0.8.0` 是 Codex Wallpaper Skin 的首个公开 Beta。它是面向 Windows 11 x64 的非官方开源工具，可以把本地图片、视频和用户已经安装的 Wallpaper Engine 项目作为 Codex Desktop 背景，同时保留 Codex 原生界面和交互。

### 下载

- 普通用户：`CodexWallpaperSkin-Setup-v0.8.0-win-x64.exe`
- 免安装使用：`CodexWallpaperSkin-v0.8.0-portable-win-x64.zip`
- 每个文件旁都提供 `.sha256`。请在运行前核对下载文件，不要从第三方转载站获取安装包。

### 首次使用

1. 安装或完整解压程序，然后启动 Codex Wallpaper Skin。
2. 点击 **Start / reconnect Codex**。如果 Codex 已经普通启动，请先手动关闭 Codex，再点击该按钮。
3. 点击 **Scan Wallpaper Engine**，或使用 **Add local** 添加自己的图片/视频。
4. 选择壁纸并点击 **Apply selected**。
5. 不再使用壁纸时点击 **Restore Codex background**。退出控制器时使用托盘菜单 **Remove wallpaper and exit**。

最终用户不需要安装 Node.js、Python、.NET SDK 或 .NET Runtime。Wallpaper Engine 仅在使用其 Scene 或大型 Video 项目时需要，并且必须由用户自行合法安装。

### 主要能力

- 中英文界面、命名视觉预设、收藏夹和 Wallpaper Engine 当前订阅项目扫描。
- 图片和受支持视频直接加载；复杂 Scene 与大型 Video 使用 Wallpaper Engine 私有离屏窗口。
- Windows Graphics Capture、D3D11 GPU 转换、硬件 H.264 编码和不兼容设备自动回退。
- 动态流看门狗和经过脱敏的 Doctor/诊断 ZIP。
- 当前用户安装、原位升级、可选保留或删除用户设置，以及不自动关闭 Codex 的卸载流程。

### 已知限制

- 仅支持 Windows 11 x64 与官方 x64 `OpenAI.Codex` Store/MSIX 包。
- 控制器必须留在托盘中才能继续生成动态背景。
- 当前稳定 H.264 4:2:0 路径不转发鼠标互动，且不能保证与 Wallpaper Engine 直接桌面合成逐像素一致。
- Scene 的帧率和清晰度取决于壁纸复杂度、Wallpaper Engine 设置、显卡、分辨率和系统负载；`60 FPS` 是目标而非保证。
- 安装包尚未代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。不要为运行本软件而全局关闭 Windows 安全功能。

## English

`v0.8.0` is the first public Beta of Codex Wallpaper Skin. It is an unofficial open-source Windows 11 x64 companion that presents local images, videos, and the user's installed Wallpaper Engine projects behind the native Codex Desktop interface.

### Downloads

- Recommended: `CodexWallpaperSkin-Setup-v0.8.0-win-x64.exe`
- Portable: `CodexWallpaperSkin-v0.8.0-portable-win-x64.zip`
- A matching `.sha256` file is supplied for every download. Verify it before running the application and do not use third-party mirrors.

### First use

1. Install the application or fully extract the portable ZIP, then start Codex Wallpaper Skin.
2. Choose **Start / reconnect Codex**. If Codex is already running normally, close it manually first and choose the button again.
3. Choose **Scan Wallpaper Engine**, or use **Add local** for your own image/video.
4. Select a wallpaper and choose **Apply selected**.
5. Choose **Restore Codex background** when finished. Use **Remove wallpaper and exit** from the notification-area menu to stop the controller.

End users do not need Node.js, Python, the .NET SDK, or a separately installed .NET Runtime. Wallpaper Engine is needed only for its Scene and large Video projects and must be legally installed by the user.

### Highlights

- English/Chinese UI, named visual presets, personal collections, and current-subscription Wallpaper Engine scanning.
- Direct image/supported-video loading plus a private Wallpaper Engine window for complex Scenes and large Videos.
- Windows Graphics Capture, D3D11 GPU conversion, hardware H.264, and an automatic compatibility fallback.
- A live-stream watchdog plus shareable, redacted Doctor/support reports.
- Per-user setup, in-place upgrades, optional user-data retention/removal, and uninstall behavior that never closes Codex automatically.

### Known limitations

- Only Windows 11 x64 and the official x64 `OpenAI.Codex` Store/MSIX package are supported.
- The controller must remain in the notification area to keep generating a dynamic background.
- The stable H.264 4:2:0 path does not forward pointer interaction and cannot be pixel-identical to Wallpaper Engine's direct desktop composition.
- Scene clarity and frame rate depend on wallpaper complexity, Wallpaper Engine settings, GPU, resolution, and system load. `60 FPS` is a target, not a guarantee.
- The installer is not code-signed. Windows may show an unknown-publisher or SmartScreen warning. Do not disable Windows security globally to run this application.
