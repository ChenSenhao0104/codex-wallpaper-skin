# Codex Wallpaper Skin v0.8.1 Beta

[English](#english) | [简体中文](#简体中文)

## 简体中文

`v0.8.1` 是首个公开 Beta 的补丁版本，重点修复浅色 Codex 主题下弹窗、菜单、设置卡片和输入区域可能出现的低对比度问题。深色主题的既有表现保持不变。

> [!IMPORTANT]
> **下载前请确认兼容性：本版本仅支持 Windows 11 x64，以及官方 x64 `OpenAI.Codex` Store/MSIX 桌面包。macOS、Linux、Windows ARM64、Windows x86、非打包版和改名副本均不支持。请勿在不受支持的系统上下载安装包。**

### 下载

- 推荐安装版：`CodexWallpaperSkin-Setup-v0.8.1-win-x64.exe`
- 免安装便携版：`CodexWallpaperSkin-v0.8.1-portable-win-x64.zip`
- 同时下载对应的 `.sha256`，运行前核对文件；不要从第三方转载站获取安装包。

### 本版改进

- 界面面板和文字的明暗基准现在跟随 Codex 当前主题，而不是跟随壁纸亮度。
- 浅色主题使用浅色半透明面板和深色文字，避免白底白字或低对比度。
- 账户菜单、对话框、下拉列表、工具提示等小浮层获得更稳定的高对比度背景。
- 壁纸生效期间切换 Codex 明暗主题时，会自动重新计算界面配色。
- 移除壁纸时会完整清理新增的主题标记、浮层标记和观察器。
- 保留 v0.8.0 的 GPU 直通、自动回退、看门狗与 Doctor 诊断能力。

### 安装与升级

1. 已安装 `v0.8.0` 的用户先从托盘选择 **Remove wallpaper and exit**。
2. 运行 `v0.8.1` 安装器并选择原安装位置，即可原位升级；壁纸库、预设和用户设置会保留。
3. 启动后点击 **Start / reconnect Codex**，再应用壁纸。

最终用户无需安装 Node.js、Python、.NET SDK 或 .NET Runtime。只有使用 Wallpaper Engine Scene 或大型 Video 项目时才需要用户自行合法安装 Wallpaper Engine。

### 已知限制

- 仅支持 Windows 11 x64 与官方 x64 `OpenAI.Codex` Store/MSIX 包。
- 控制器必须留在托盘中才能继续生成动态背景。
- 当前稳定 H.264 4:2:0 路径不转发鼠标互动，也不能保证与 Wallpaper Engine 直接桌面合成逐像素一致。
- Scene 清晰度和帧率取决于壁纸复杂度、Wallpaper Engine 设置、显卡、分辨率和系统负载；`60 FPS` 是目标而非保证。
- 安装包尚未代码签名，Windows 可能显示未知发布者或 SmartScreen 提示。不要为运行本软件而全局关闭 Windows 安全功能。

## English

`v0.8.1` is a patch for the first public Beta. It focuses on low-contrast popovers, menus, settings cards, and input surfaces when Codex uses its light theme. Existing dark-theme behavior is preserved.

> [!IMPORTANT]
> **Check compatibility before downloading: this build supports only Windows 11 x64 with the official x64 `OpenAI.Codex` Store/MSIX desktop package. macOS, Linux, Windows ARM64, Windows x86, unpackaged builds, and renamed copies are unsupported. Do not install this package on an unsupported system.**

### Downloads

- Recommended installer: `CodexWallpaperSkin-Setup-v0.8.1-win-x64.exe`
- Portable build: `CodexWallpaperSkin-v0.8.1-portable-win-x64.zip`
- Download the matching `.sha256` file and verify the package before running it. Do not use third-party mirrors.

### Improvements

- Surface and text polarity now follows the active Codex theme instead of wallpaper brightness.
- Light mode uses light translucent surfaces with dark readable text, preventing white-on-white combinations.
- Account menus, dialogs, lists, tooltips, and other small elevated surfaces receive a more reliable high-contrast background.
- Changing the Codex light/dark theme while a wallpaper is active triggers automatic palette recalculation.
- Restore removes the added theme markers, elevated-surface markers, and observers completely.
- The GPU path, compatibility fallback, watchdog, and privacy-conscious Doctor diagnostics from v0.8.0 remain available.

### Install or upgrade

1. Existing `v0.8.0` users should choose **Remove wallpaper and exit** from the notification-area menu.
2. Run the `v0.8.1` installer and select the existing installation directory. The in-place upgrade preserves the wallpaper library, presets, and settings.
3. Start the controller, choose **Start / reconnect Codex**, and apply a wallpaper.

End users need no Node.js, Python, .NET SDK, or separately installed .NET Runtime. Wallpaper Engine is required only for its Scene and large Video projects and must be legally installed by the user.

### Known limitations

- Only Windows 11 x64 and the official x64 `OpenAI.Codex` Store/MSIX package are supported.
- The controller must remain in the notification area to keep generating a dynamic background.
- The stable H.264 4:2:0 path does not forward pointer interaction and cannot be pixel-identical to Wallpaper Engine's direct desktop composition.
- Scene clarity and frame rate depend on wallpaper complexity, Wallpaper Engine settings, GPU, resolution, and system load. `60 FPS` is a target, not a guarantee.
- The installer is not code-signed. Windows may show an unknown-publisher or SmartScreen warning. Do not disable Windows security globally to run this application.
