The files in this directory are application screenshots captured by project
owner Silas Chenery for Codex Wallpaper Skin documentation.

The Codex Wallpaper Skin interface and screenshot composition are project
documentation. Any third-party background artwork, characters, trademarks, or
application interfaces visible inside a screenshot remain the property of
their respective rights holders and are not relicensed under Apache-2.0. They
are shown only to demonstrate local interoperability and runtime behavior.

No importable Wallpaper Engine project, original wallpaper source file, or
third-party media package is included in this directory, the application, or
the installer. Short GIF and MP4 screen recordings used by the README are
hosted as GitHub Release assets instead of being committed to Git history.
