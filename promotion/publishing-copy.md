### Description

我最初只是想给 Codex 换一张背景，最后把它做成了一款可以安装的 Windows 应用：Codex Wallpaper Skin。

它可以把本地图片、MP4/WebM 视频和用户已经安装的 Wallpaper Engine 项目作为 Codex Desktop 的独立背景，同时提供自动配色、视觉预设、性能档位、隐私脱敏 Doctor 和一键恢复。

GitHub / 下载：
https://github.com/ChenSenhao0104/codex-wallpaper-skin

当前兼容范围：Windows 11 x64，以及官方 x64 OpenAI.Codex Store/MSIX 桌面包。macOS、Linux、Windows ARM64/x86 和非打包版当前不支持。安装包仍处于未签名 Beta 阶段，请只从 GitHub Releases 下载并核对 SHA-256。

普通本地图片和视频不要求安装 Wallpaper Engine；Wallpaper Engine 只在使用它的 Scene 或大型 Video 项目时需要。本项目不附带或重新分发任何 Wallpaper Engine 壁纸。

本项目是独立社区项目，与 OpenAI、Valve 或 Wallpaper Engine 无隶属、认可或赞助关系。画面和音乐署名见视频结尾及置顶评论。

## Reddit r/codex

### Title

I built an open-source Windows app that brings local videos and Wallpaper Engine scenes into Codex Desktop

### Body

I originally wanted to change one Codex background. It turned into Codex Wallpaper Skin, a Windows companion that can present local images, MP4/WebM videos, and installed Wallpaper Engine projects behind the real Codex UI.

Codex and the desktop use independent wallpapers. Complex Scene projects are rendered by the user's local Wallpaper Engine installation, while the app adds adaptive colors, visual presets, pause/throttle controls, privacy-redacted diagnostics, and one-click restore.

Current boundary: Windows 11 x64 with the official x64 OpenAI.Codex Store/MSIX desktop package. It is an unsigned public Beta. Wallpaper Engine is optional unless you use its Scene or large Video projects. This is an independent community project and is not affiliated with OpenAI, Valve, or Wallpaper Engine.

GitHub and downloads: https://github.com/ChenSenhao0104/codex-wallpaper-skin
