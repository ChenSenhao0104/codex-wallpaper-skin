# Community Code of Conduct / 社区行为准则

[English](#english) | [简体中文](#简体中文)

## 简体中文

Codex Wallpaper Skin 欢迎不同经验、背景与观点的用户和贡献者参与。参与本项目时，请：

- 尊重他人，以问题、证据和可复现信息为中心讨论；
- 不骚扰、侮辱、歧视、威胁或公开他人的私人信息；
- 提交截图、日志和诊断包前主动检查隐私内容与第三方素材；
- 尊重 Wallpaper Engine 作者、软件厂商及其他权利人的许可与署名要求；
- 不使用 Issue、Discussion、PR 或评论发布垃圾广告、诱导下载、恶意代码或无关推广；
- 接受维护者为保护用户安全、项目范围和社区秩序所作的合理管理决定。

维护者可编辑或移除违反上述规则的内容，并可限制持续或严重违规者的参与。安全漏洞请按照 [SECURITY.md](SECURITY.md) 私下报告；其他行为问题可通过仓库维护者的 GitHub 主页联系。

## English

Codex Wallpaper Skin welcomes users and contributors with different levels of experience, backgrounds, and viewpoints. When participating in this project:

- Treat others with respect and keep technical discussion focused on evidence and reproducible behavior.
- Do not harass, insult, discriminate against, threaten, or expose another person's private information.
- Review screenshots, logs, and diagnostic bundles for private data and third-party material before sharing them.
- Respect the licenses and attribution requirements of Wallpaper Engine creators, software vendors, and other rights holders.
- Do not use Issues, Discussions, pull requests, or comments for spam, deceptive downloads, malicious code, or unrelated promotion.
- Accept reasonable moderation decisions made to protect user safety, project scope, and the health of the community.

Maintainers may edit or remove content that violates these rules and may restrict participation after repeated or severe violations. Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md). For other conduct concerns, contact the maintainer through the repository owner's GitHub profile.
